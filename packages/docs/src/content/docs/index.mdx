## The short version

Working on a branch that touches more than one service means running the whole project. Usually
that means one local copy, one branch at a time, and a database that no longer matches whatever
you switch back to.

sandboxr gives each branch its own running copy of the project. Every service, every front-end,
its own database and its own file storage — in one container, made from one git worktree, and
reachable in a browser at its own address.

```bash
cd .worktrees/feat-123
sandboxr up
# https://feat-123.app.acme.sbx.lcl
# https://feat-123.api.acme.sbx.lcl
```

Several run at once, on a laptop or a server. Two of them do not share a database, a port, an
uploads bucket or an installed dependency tree they can break for each other. Deleting one
deletes all of it, and never touches your branch.
